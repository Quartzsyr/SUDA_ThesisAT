# Soochow University Undergraduate Thesis Format (2020)

Source file used for this workspace:
`D:\syr\毕设\相关文档\苏州大学本科毕业设计装订及打印格式（2020版）.pdf`

## Binding order for thesis

1. Cover
2. Originality statement and authorization statement
3. Thesis
4. Task assignment
5. Foreign-language literature and Chinese translation
6. Literature review or reading report
7. Midterm inspection form
8. Defense record form
9. Grade evaluation form
10. Detection report (concise version)

## Internal thesis order

1. Chinese title, abstract, and keywords
2. English title, abstract, and keywords
3. Table of contents
4. Main text
5. Conclusion
6. References
7. Acknowledgements
8. Appendices

## Typography and layout

- Paper: A4, single-sided
- Margins: top 3.3 cm, bottom 2.7 cm, left 2.5 cm, right 2.5 cm
- Binding line: left 0.5 cm
- Line spacing: 1.5 lines
- Paragraph spacing: 0 pt before and after
- First-line indent: 2 characters
- Header distance: 2.6 cm
- Footer distance: 2.0 cm
- Header text: `苏州大学本科生毕业设计（论文）`
- Header style: centered, small-five Song, with horizontal line

## Font rules

- Chinese title: small-two HeiTi
- Chinese abstract and keywords: small-four Song
- English title: small-two Times New Roman
- English abstract and keywords: small-four Times New Roman
- TOC: four-point Song
- TOC chapter titles: four-point HeiTi
- TOC section titles: four-point Song
- Main text Chinese: Song
- Main text English: Times New Roman
- Heading font: bold
- Chapter title size: small-three
- Main text size: small-four

## Page numbering

- No page numbers on cover or declaration pages
- Abstract and TOC: lowercase Roman numerals
- Main text onward: centered Arabic numerals with hyphens, such as `-1-`
- References, appendices, and acknowledgements continue the main-text numbering
- Foreign-language translation and literature review use the same layout rules as the thesis body but do not need page numbers

## Citation and references

- In-text citations use right-upper-corner bracketed numbers
- Multiple citations in one location use commas inside one pair of brackets
- Consecutive ranges use a short hyphen
- Reference list follows GB/T 7714-2015

## Cover handling notes

- The cover page should use the school-provided electronic template rather than being recreated manually.
- If a concrete cover `.doc` or `.docx` is provided, treat that file as the authoritative source for cover spacing, field order, and decorative elements.
- The supplied cover template `D:\syr\毕设\相关文档\本科毕业设计（论文）封面-word版本.docx` uses one centered title paragraph plus one information table.
- Typical editable cover fields for that template are `学院(部)`、`题   目`、`年  级`、`专业`、`班  级`、`学号`、`姓  名`、`指导老师`、`职称`、`论文提交日期`.
- After editing the cover, manually verify centered alignment, title wrapping, row height, cell width, and whether long values still look visually balanced.
