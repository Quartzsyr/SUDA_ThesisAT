Built for the final draft

不用更复杂的工具，
完成更清晰的交付。

SUDA ThesisAT 不是泛化写作平台。它服务于论文完成前最易出错的流程：导入正文、补全封面、核对版式、导出成果。

原生桌面架构确保文件留在本地；预览优先的界面让每一次格式调整都看得见。
