Overview

克制、直接、以交付为目标。

这不是一个泛化写作平台，而是一个更适合论文定稿阶段的工具。界面围绕预览和输出组织，减少在多个软件之间反复切换的成本。

项目以原生桌面应用为核心，采用 PyQt6、PyMuPDF、python-docx 与 PyInstaller，强调离线可用、结构清晰和稳定导出。

Workflow

论文排版工作流程

02

04

导出成果

输出 PDF 与 DOCX，用于提交和归档。
